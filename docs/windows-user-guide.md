# 听码 · Windows 使用说明

适用于 Windows 10/11 的 64 位 x64 电脑。**解压后双击 `Tingma.exe` 即可运行，不需要安装 Python。** 不要直接在压缩包中打开程序。首次打开时会解压内置组件，请稍等窗口出现。

## 第一次使用

1. 双击 **Tingma.exe**。
2. 点击 **API 设置**，填写自己申请的 API Key；接口协议、地址和模型按服务商控制台填写。点击 **测试连接**，然后 **保存设置**。Key 只保留到退出软件，下次打开需重新填写。
3. 打开直播并播放声音，确认能从 Windows 默认播放设备听到直播。
4. 在听码中点击 **准备系统声音**。软件识别电脑播放的声音，不使用麦克风。
5. 勾选 **仅预览，不自动填入**，设置数字的最少和最多位数。已知固定长度时，例如六位，设为 **6 至 6**。
6. 点击悬浮 **我想要** 或按 **F8**，试听一轮。检查最终结果，确认能保留前导零并符合需要的位数。

默认接口设置如下；如果服务商控制台给出的设置不同，请以控制台为准。

| 设置 | 软件默认值 |
| --- | --- |
| 接口协议 | 千问 Audio 3.0 · 实时语音 |
| 完整 API 地址 | `wss://dashscope.aliyuncs.com/api-ws/v1/inference` |
| 模型名称 | `qwen-audio-3.0-asr-flash-streaming` |
| API Key | 填写自己的 Key |

“测试连接”不上传声音，也不代表已完成真实语音识别；请通过上面的预览步骤检查实际效果。

## 填入当前输入框

1. 在 **输出到** 中选择 **当前输入框 · Ctrl+V 粘贴**，取消勾选“仅预览”。
2. 在微信、文本编辑器等软件中，点击需要输入数字的位置，把光标放好。
3. 点击悬浮 **我想要** 或按 **F8**，等待本轮识别结束。
4. 软件显示本轮目标，将通过检查的数字放进剪贴板并执行一次 **Ctrl+V**，**不会按回车发送消息**。请到目标软件核对结果。

光标在微信就粘贴到微信，在编辑器就粘贴到编辑器。识别期间保持窗口、光标和内容不变；切换目标会取消粘贴。数字会留在剪贴板并替换原内容。如果目标没有响应，可自行 Ctrl+V；不要反复触发软件，以免重复输入。

实时接口读到“扣 / 飘”后的完整数字或四则算式，后面一出现其他内容，就停止收音并请求最终识别。例如“29一件飘一个9全羊毛”，不必等主播讲完商品介绍。接口确认数字后立即处理本轮；中间文字仍可能改动，因此只用最终结果填写。HTTP 短音频接口须先结束收音才能识别。

## 识别后发送抖音弹幕

电脑需安装 Microsoft Edge。

1. 在 **输出到** 中选择 **抖音网页版弹幕**。
2. 填入完整直播间地址，例如 `https://live.douyin.com/498488958432`，点击 **打开 Edge**。短分享链接需先打开，再复制最终直播间地址。
3. 在软件打开的专用 Edge 窗口中登录抖音、播放直播。这个窗口需要单独登录。
4. 确认 API 已配置、系统声音已准备、预览结果正确，再取消“仅预览”。
5. 勾选 **识别后自动发送一条数字弹幕**；每次重新启动软件都需要开启。
6. 保持直播间标签页可见、弹幕框为空，点击 **我想要 / F8**。最终数字通过检查后，软件填写并点击发送一次。

每次点击只识别一轮，不会持续自动刷弹幕。已有草稿、切换直播间、刷新页面或控件变化都会阻止提交。发送至少间隔 3 秒，30 秒内相同数字不会重复提交。

“已提交一次，输入框已清空”表示网页已执行提交，请在直播间核对是否显示。若提示 **发送状态不明**，先检查直播间，再点 **我已检查直播间，解除发送暂停**；软件不会自动重发。

## 数字纠错规则

只有“扣 / 飘”后面的内容才作为口令；最终结果只允许 **0–9**，共 1–32 位，并保留前导零。

| 识别内容 | 结果 |
| --- | --- |
| 扣零零八 | `008` |
| 扣幺二三 | `123` |
| 扣两个零 | `00` |
| 扣三个八 | `888` |
| 扣两个零，八 | `008` |
| 这件29，扣一个00 | `00` |
| 库存18，飘一个零0九 | `009` |
| 这件30扣一个2乘3 | `6` |
| 29一件飘一个9全羊毛 | `9` |
| 扣2加3乘4全羊毛 | `14` |
| 飘9除3减1这个颜色好看 | `2` |
| 飘二乘以三 / 扣2×3 | `6` |
| 00 / 打00 / 发00 | 没有“扣 / 飘”，不填写 |
| 飘一个数字9 / 飘一个数字九 | `9` |
| 扣一个数字零零八 | `008` |
| 扣个数字一2三 | `123` |
| 两个 m、O08、1.2、不是123是456 | 含义或格式不符合要求，拒绝自动填写 |

从第一个明确的“扣 / 飘”后开始，只读取数字及加减乘除，遇到其他内容就结束，不再收集后面的数字。例如“飘9全羊毛”“飘9元”“飘9或者8”都取 `9`；“扣12m3”取 `12`，不会把后面的 3 拼上。“一个”属于提示语，不会多填一位；“飘两个9”得到 `99`。没有“扣 / 飘”或提示词前有“不要”等否定时，不填写。

四则运算支持加/加上/+、减/减去/-、乘/乘以/×/*、除/除以/÷/。先乘除、后加减，同级从左到右。只输出非负整数；不完整算式、除零、结果为负数或非整数、小数操作数、括号表达式不填写。单独“扣008”仍为 `008`，参与算式后按数值计算。

位数不符时不补零、不截断。数字被听成另一个数字时，格式检查可能发现不了，所以首次使用请先预览。

## 操作与常见问题

- **取消本轮：** 再次点击悬浮按钮或按 F8。若 Esc 快捷键注册成功，也可以按 Esc。已经提交的弹幕不会被撤回；如留下数字草稿，请自行检查。
- **移动悬浮按钮：** 按住右键拖动。F8 被其他软件占用时，使用悬浮按钮。
- **没有声音或识别不准：** 确认直播使用 Windows 默认播放设备，关闭其他不需要的声音；背景音乐可能影响识别。更换播放设备后，关闭听码再打开，重新准备系统声音。
- **识别需要等待：** 实时接口遇到数字/算式后的其他文字就停止收音，再等最终转写确认；没有口令时最多收音 12 秒，也不会把价格或裸数字填入。HTTP 接口在讲话后短暂停顿时结束收音，再上传识别。网络连接仍在结束时，稍后再开始下一轮。
- **API 报错：** 检查 Key、模型、地址、地域及服务额度是否匹配。不要把 Key 放进接口地址或发给别人。
- **无法自动填写：** 让听码与目标软件都以普通权限运行，先用普通文本框测试；也可以复制结果手动粘贴。

日常打开的文件是 **Tingma.exe**。同目录的 `SHA256.txt` 和 `build-check.json` 是校验资料，无需运行。
